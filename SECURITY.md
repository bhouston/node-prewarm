# Security policy

Security fixes target the latest published release. Upgrade to the latest version
before reporting; older releases do not receive backported security fixes.

Report suspected vulnerabilities privately to Ben Houston at **ben@ben3d.ca**.
Include the affected version, reproduction steps, impact, and any proposed fix.
Do not post exploit details in a public issue before a fix and disclosure plan
have been coordinated. We will assess the report and coordinate disclosure with
the reporter; no guaranteed response time is offered.
